# Usage map and combined usage — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A calendar of daily usage — one square per day per provider, plus a combined row — backfilled from both providers so it is useful the day it ships.

**Architecture:** A new `usage_day` table holds one row per provider per local day, written two ways: rolled up from the samples Altim already records, and backfilled from each provider's own history. Rendering is a custom Avalonia control fed by a view model; the scale is quantile-based and computed in pure code. No new projects.

**Tech Stack:** .NET 10, Avalonia 12.1.2, Microsoft.Data.Sqlite, CommunityToolkit.Mvvm, xUnit v3.

**Spec:** `docs/superpowers/specs/2026-09-17-usage-map-design.md`

## Global Constraints

- Warnings are errors. `dotnet build Altim.sln -c Release` must stay at 0 warnings.
- **A null is a null.** An unreported figure is `null`, never `0`, in every layer including the database.
- **Percentages are never combined across providers.** Tokens may be summed; percentages may only be listed side by side.
- **Unknown and zero must render differently** — hairline outline versus faintest fill.
- No project, path, prompt, command or account identifier may reach storage, a log, or the UI.
- XAML consumes every `Altim*` brush/colour/shadow with `{DynamicResource}`; a `StaticResource` on a theme key silently freezes the light value and a source-shape test fails the build.
- Tests are xUnit v3. Run with `dotnet test`, never `--nologo`.
- Do not edit `Altim.sln`, `Directory.Build.props`, `Directory.Packages.props`, `global.json`, `.editorconfig`.
- Commit after every task.

/// <summary>Where a day's row came from, which decides whether a later write may replace it.</summary>
public enum UsageDaySource
{
    /// <summary>Rolled up from readings Altim took itself. Authoritative.</summary>
    Observed = 0,

    /// <summary>Read from a provider's own history. Fills gaps, never overwrites an observed day.</summary>
    Backfilled = 1,
}

`UsageDay.cs`:

```csharp
namespace Altim.Core.Models;

/// <summary>
/// What one provider used on one local calendar day.
/// </summary>
/// <param name="ProviderId">The provider the day belongs to.</param>
/// <param name="Day">The user's local calendar day.</param>
/// <param name="Tokens">
/// The day's token components, or <see langword="null"/> when none were reported. A component
/// inside it may be null on its own; null means unreported and never zero.
/// </param>
/// <param name="PeakPercent">
/// The highest percentage any of that provider's windows reached that day, or
/// <see langword="null"/> when no window reported one. Never combined across providers.
/// </param>
/// <param name="Source">Whether Altim observed the day or read it from the provider's history.</param>
/// <param name="UpdatedAt">When the row was last written.</param>
public sealed record UsageDay(
    string ProviderId,
    DateOnly Day,
    TokenTotals? Tokens,
    double? PeakPercent,
    UsageDaySource Source,
    DateTimeOffset UpdatedAt)
{
    /// <summary>
    /// The day's total token volume, or <see langword="null"/> when nothing was reported.
    /// A component that was not reported contributes nothing rather than zero.
    /// </summary>
    public long? TotalTokens
    {
        get
        {
            if (Tokens is null)
            {
                return null;
            }

            long? total = null;
            foreach (long? part in new[] { Tokens.Input, Tokens.Output, Tokens.CacheRead, Tokens.CacheWrite })
            {
                if (part is { } value)
                {
                    total = (total ?? 0) + value;
                }
            }

            return total;
        }
    }
}
```

namespace Altim.Core.Abstractions;

/// <summary>
/// A provider that can report usage from before Altim was watching.

/// <remarks>

    /// </returns>

}

INSERT INTO usage_day (provider_id, day, input_tokens, output_tokens, cache_read_tokens,

VALUES ($provider, $day, $input, $output, $cacheRead, $cacheWrite, $peak, $source, $updatedAt)

  output_tokens = excluded.output_tokens,

  updated_at = excluded.updated_at
WHERE excluded.source = 'observed' OR usage_day.source = 'backfilled';
